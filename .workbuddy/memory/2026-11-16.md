## tsconfig 的 baseUrl 弃用提示

- 现象：VS Code 对 `tsconfig.json` 的 `baseUrl` 划线并提示「TS 7.0 将停止支持」。根因是编辑器内置 TS 为 6.x，而项目 `node_modules` 是 5.7.3（`vue-tsc` 用它），两者不是同一实例。
- 处理：删除 `baseUrl`，`paths` 改为 `"@/*": ["./src/*"]`（无 baseUrl 时 paths 相对 tsconfig 所在目录解析，必须带 `./`）。
- 验证：`vue-tsc --noEmit` / `tsc -p tsconfig.node.json` / `eslint .` / `vite build` 全部 0 错误；src 下 76 处 `@/` 导入全部解析成功（若 paths 失效会立刻报「找不到模块」）。
- 注意：Vite 的 `resolve.alias` 与 tsconfig `paths` 互不联动，paths 写错时 dev 仍能跑、只有类型检查会炸。
